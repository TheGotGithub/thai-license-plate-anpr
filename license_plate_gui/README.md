# License Plate GUI

หน้าเว็บสำหรับนำภาพรถเข้าระบบ (อัปโหลดเอง หรือถ่ายจากกล้อง Pi Camera โดยตรง) แล้วรัน pipeline
ตรวจจับป้ายทะเบียนทั้งหมด (`license_plate_crop` → `license_plate_ocr` → `license_plate_match`)
ในคลิกเดียว พร้อมแสดงผลลัพธ์

## โครงสร้างโฟลเดอร์

```
license_plate_gui/
├── app.py           # หน้าเว็บ Streamlit
└── startGUI.sh      # สคริปต์เปิดหน้าเว็บแบบไม่ต้อง activate venv เอง
```

## วิธีใช้งาน

1. ติดตั้ง dependencies (ใช้ไฟล์ `requirements.txt` ที่ root ของโปรเจกต์ รวมทุกโมดูลไว้ที่เดียว)
   ```
   pip install -r ../requirements.txt
   ```

2. รัน
   ```
   ./startGUI.sh
   ```
   จะเปิดหน้าเว็บที่ `http://localhost:8501` อัตโนมัติ (ไม่ต้อง activate venv เอง สคริปต์นี้เรียก
   streamlit จากใน venv ให้โดยตรง รันจากโฟลเดอร์ไหนก็ได้ไม่ต้อง cd เข้ามาก่อน)

3. เลือกวิธีนำเข้าภาพที่ด้านบนของหน้าเว็บ:
   - **อัปโหลดภาพ** — เลือกไฟล์ภาพรถจากเครื่อง แล้วกด "ประมวลผล"
   - **ถ่ายภาพจากกล้อง Pi Camera** — ใช้ได้เฉพาะบน Raspberry Pi ที่ต่อกล้องเท่านั้น
     จะเห็นภาพสด (live stream) ให้เล็งมุมกล้อง แล้วกด "ถ่ายภาพและประมวลผล"
     (ถ้าเปิดบนเครื่องที่ไม่มี `picamera2` เช่น Mac จะแสดงข้อความแจ้งเตือนแทนการ crash)

   ทั้งสองแบบระบบจะรันตรวจจับป้าย, OCR, และจับคู่จังหวัดให้ครบ แล้วแสดงภาพป้ายทะเบียนที่ตรวจพบ
   พร้อมเลขทะเบียนและจังหวัดที่อ่านได้

## หมายเหตุ

ภาพที่ได้มา (อัปโหลดหรือถ่าย) จะถูกบันทึกไว้ใน `../license_plate_crop/input_images/` และผลลัพธ์
แต่ละขั้นตอนจะถูกเขียนทับไฟล์ output เดิมของแต่ละโมดูล (`output_crops/`, `output_text/`, `output_data/`)
เช่นเดียวกับตอนรัน `run_pipeline.py` ตามปกติ

โหมดถ่ายภาพใช้กล้องร่วมกับ `license_plate_capture/mjpeg_stream.py` — เปิดกล้องได้ทีละ 1 หน้าเว็บ
เท่านั้น ถ้าเปิด `license_plate_capture/capture_gui.py` ค้างไว้พร้อมกัน กล้อง/พอร์ตสตรีมจะชนกัน
